1. **Negotiated deals**: Some platforms have better negotiated rates with certain retailers

3. **Promotional stacking**: Some retailers run higher-paying campaigns through specific platforms
4. **Tracking and validation**: Different platforms have different efficiency rates for successfully tracking purchases
5. **Payment method bonuses**: Some platforms offer extra cashback when you choose gift cards over direct bank transfers
